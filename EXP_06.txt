================================================================================
EXPERIMENT 6: FILE TRANSFER BETWEEN TWO VIRTUAL MACHINES (UBUNTU & KALI)
================================================================================

AIM:
To send and receive files between Ubuntu VM and Kali Linux VM using NFS, 
Shared Folders, SSH/SCP, and FTP.

================================================================================
METHOD 1: NFS (NETWORK FILE SYSTEM) - [MAIN EXAM METHOD]
================================================================================
(Ubuntu is the SERVER, Kali is the CLIENT)

--------------------------------------------------------------------------------
STEP 1: NETWORK SETUP IN VIRTUALBOX (DO THIS FOR BOTH VMs)
--------------------------------------------------------------------------------
1. Turn OFF both Ubuntu and Kali VMs.
2. In VirtualBox, click "Ubuntu VM" -> Click "Settings" (gear icon) -> Click "Network".
   - Adapter 1: Attached to -> Select "Host-only Adapter".
   - Adapter 2: Click "Enable Network Adapter" -> Attached to -> Select "NAT".
   - Click "OK".
3. Do the EXACT SAME thing for "Kali VM":
   - Adapter 1: "Host-only Adapter"
   - Adapter 2: "NAT"
   - Click "OK".
4. Now start (Power ON) both Ubuntu and Kali.

--------------------------------------------------------------------------------
STEP 2: FIND IP ADDRESS OF BOTH VMs
--------------------------------------------------------------------------------
1. On UBUNTU VM:
   Open Terminal (Ctrl + Alt + T) and type:
   ip a
   -> Look at Adapter 1 (enp0s3). Find your IP: e.g. 192.168.56.103

2. On KALI VM:
   Open Terminal and type:
   ip a
   -> Look at Adapter 1 (eth0). Find your IP: e.g. 192.168.56.104

3. Write down both IPs on a paper:
   - Ubuntu IP = 192.168.56.103
   - Kali IP   = 192.168.56.104

--------------------------------------------------------------------------------
STEP 3: SETUP NFS SERVER ON UBUNTU VM
--------------------------------------------------------------------------------
Open Terminal in UBUNTU and run these commands one by one:

1. Update and install NFS Server:
   sudo apt update
   sudo apt install nfs-kernel-server -y

2. Create a folder to share:
   sudo mkdir -p /srv/nfs/sharedfolder

3. Give full permission so Kali can read and write:
   sudo chmod 777 /srv/nfs/sharedfolder

4. Open the export config file in text editor:
   sudo nano /etc/exports

5. Inside the editor, use down-arrow key to go to the VERY LAST line, and type:
   /srv/nfs/sharedfolder *(rw,sync,no_subtree_check,no_root_squash)

6. How to save and exit nano:
   - Press Ctrl + O
   - Press Enter
   - Press Ctrl + X

7. Apply the changes and restart NFS:
   sudo exportfs -a
   sudo systemctl restart nfs-kernel-server

--------------------------------------------------------------------------------
STEP 4: SETUP NFS CLIENT ON KALI LINUX VM
--------------------------------------------------------------------------------
Open Terminal in KALI and run these commands one by one:

1. Install NFS Client:
   sudo apt update
   sudo apt install nfs-common -y

2. Create a folder where you will view the shared files:
   sudo mkdir -p /mnt/nfs/sharedfolder

3. Connect (Mount) Ubuntu's shared folder to Kali:
   (Replace 192.168.56.103 with YOUR Ubuntu IP)
   sudo mount 192.168.56.103:/srv/nfs/sharedfolder /mnt/nfs/sharedfolder

4. Check if connection is successful:
   df -h | grep nfs
   -> If you see Ubuntu's IP listed, it is 100% connected!

--------------------------------------------------------------------------------
STEP 5: TEST AND SHOW OUTPUT TO EXAMINER (SUCCESS PROOF!)
--------------------------------------------------------------------------------

TEST A: SEND FILE FROM UBUNTU -> READ IT ON KALI
1. In UBUNTU Terminal, create a file:
   echo "Hello Examiner, file sent from Ubuntu" | sudo tee /srv/nfs/sharedfolder/ubuntu_file.txt

2. In KALI Terminal, open and see that file:
   cat /mnt/nfs/sharedfolder/ubuntu_file.txt
   -> OUTPUT: Hello Examiner, file sent from Ubuntu

TEST B: CREATE FILE ON KALI -> READ IT ON UBUNTU
1. In KALI Terminal, write a file:
   echo "Hello Examiner, file sent from Kali" > /mnt/nfs/sharedfolder/kali_file.txt

2. In UBUNTU Terminal, check if file arrived:
   cat /srv/nfs/sharedfolder/kali_file.txt
   -> OUTPUT: Hello Examiner, file sent from Kali

================================================================================
METHOD 2: SHARED FOLDERS (USING WINDOWS HOST)
================================================================================
1. On your Windows desktop, make a new folder: C:\VMShared
2. Put any text file inside it: test.txt
3. In VirtualBox: Settings of VM -> Shared Folders -> Click "+" icon.
   - Folder Path: C:\VMShared
   - Folder Name: VMShared
   - Tick "Auto-mount"
   - Click OK.
4. Do this for both VMs.
5. In both VMs, open terminal and type:
   sudo usermod -aG vboxsf $USER
   sudo reboot
6. After restart, open terminal and check:
   ls /media/sf_VMShared
   -> You will see test.txt inside both VMs!

================================================================================
METHOD 3: SSH AND SCP (SECURE COPY)
================================================================================
1. On both VMs, install SSH:
   sudo apt update && sudo apt install openssh-server -y
2. Send a file from Kali to Ubuntu:
   (Replace ubuntu_username and 192.168.56.103 with your Ubuntu details)
   scp myfile.txt ubuntu_username@192.168.56.103:/home/ubuntu_username/
3. Type Ubuntu password. The file is copied directly!

================================================================================
METHOD 4: FTP (FILE TRANSFER PROTOCOL)
================================================================================
1. On Ubuntu (Server):
   sudo apt install vsftpd -y
   sudo nano /etc/vsftpd.conf
   (Ensure 'write_enable=YES' is set, save with Ctrl+O, Enter, Ctrl+X)
   sudo systemctl restart vsftpd
2. On Kali (Client):
   sudo apt install ftp -y
   ftp 192.168.56.103
   (Enter Ubuntu username and password)
   ftp> put localfile.txt    (Upload file)
   ftp> get remotefile.txt   (Download file)
   ftp> bye                  (Exit)

--------------------------------------------------------------------------------
SIMPLE VIVA QUESTIONS FOR EXAMINER:
--------------------------------------------------------------------------------
Q1: What does NFS stand for?
A: Network File System. It allows one machine to mount and access folders on another machine over the network.

Q2: What port does NFS and SSH use?
A: NFS uses port 2049. SSH/SCP uses port 22. FTP uses ports 20 and 21.

Q3: What does 'rw' and 'sync' mean in NFS /etc/exports?
A: 'rw' means Read and Write. 'sync' means write changes to disk immediately.
