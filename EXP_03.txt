================================================================================
EXPERIMENT 3: COLD MIGRATION OF VM (MOVE VM USING OVA APPLIANCE)
================================================================================

AIM:
To move (migrate) a Virtual Machine from Computer 1 (Source Host) to Computer 2 
(Destination Host) while the VM is turned OFF (Cold Migration) using the OVA file method,
and show that all files remain safe without any loss.

WHAT IS COLD MIGRATION?
Cold Migration means moving a Virtual Machine while it is completely shut down (turned off).

WHAT IS AN OVA FILE?
An OVA file is like a zip file that packs the entire virtual machine (hard disk + settings)
into one single portable file.

--------------------------------------------------------------------------------
STEP-BY-STEP PROCEDURE:
--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
PART 1: ON COMPUTER 1 (WHERE YOUR VM CURRENTLY EXISTS)
--------------------------------------------------------------------------------

STEP 1: Create a Test File Inside Your VM (Proof of Data)
1. Turn ON your Ubuntu VM on Computer 1.
2. Open Terminal (Ctrl + Alt + T) and type:
   echo "Cold Migration Test File - My Data is Safe" > ~/my_proof.txt
3. Check the file content:
   cat ~/my_proof.txt
   -> Output: Cold Migration Test File - My Data is Safe

STEP 2: Turn OFF the VM Completely
In the terminal, type:
   sudo shutdown -h now
(Wait until the VM window closes and the VM status says "Powered Off").

STEP 3: Export the VM as an OVA File
1. Open Oracle VM VirtualBox on Computer 1.
2. Click your VM to select it.
3. Click menu at the top: "File" -> "Export Appliance..." (or press Ctrl + E).
4. In the window:
   - Make sure your VM is selected -> Click "Next".
   - Format: Select "Open Virtualization Format 1.0".
   - File: Click the folder icon and choose where to save, e.g., Desktop or USB Drive.
     Give it a name like "MyMigratedVM.ova".
   - Click "Next".
5. Click "Finish" (or "Export").
6. A progress bar will appear. Wait 2 to 3 minutes until it finishes 100%.

STEP 4: Copy the OVA File to a Pendrive
Copy the "MyMigratedVM.ova" file to your USB pendrive or external drive.
Eject the pendrive from Computer 1.

--------------------------------------------------------------------------------
PART 2: ON COMPUTER 2 (THE NEW COMPUTER)
--------------------------------------------------------------------------------

STEP 5: Plug Pendrive into Computer 2
1. Plug your USB pendrive into Computer 2.
2. Copy the "MyMigratedVM.ova" file onto Computer 2 (like on D: drive or Desktop).

STEP 6: Import the VM in VirtualBox on Computer 2
1. Open Oracle VM VirtualBox on Computer 2.
2. Click menu at the top: "File" -> "Import Appliance..." (or press Ctrl + I).
3. Click the yellow folder icon -> Select "MyMigratedVM.ova" -> Click "Open".
4. Click "Next".
5. In Appliance Settings:
   - Look for "MAC Address Policy": Choose "Generate new MAC addresses for all network adapters".
6. Click "Finish" (or "Import").
7. Wait 2 minutes for the progress bar to reach 100%.

--------------------------------------------------------------------------------
PART 3: VERIFY AND SHOW SUCCESS TO EXAMINER!
--------------------------------------------------------------------------------
STEP 7: Start the Imported VM
1. You will see "MyMigratedVM" in the VirtualBox list on Computer 2!
2. Click it and click the green "Start" arrow.
3. Log in with your same password.

STEP 8: Check Your Test File
Open Terminal in the VM and type:
   cat ~/my_proof.txt
   -> OUTPUT: Cold Migration Test File - My Data is Safe

SUCCESS! All your settings, files, and programs were moved from Computer 1 to Computer 2
with zero loss!

--------------------------------------------------------------------------------
SUPER SIMPLE VIVA QUESTIONS:
--------------------------------------------------------------------------------
Q1: What is Cold Migration?
A: Moving a virtual machine from one host computer to another while the VM is turned OFF (shut down).

Q2: What is Live Migration?
A: Moving a virtual machine while it is turned ON and running, with zero downtime.

Q3: What does OVA stand for?
A: Open Virtualization Appliance. It is an open format archive containing the VM's disk and configuration.

Q4: Why should we generate a new MAC address when importing?
A: To prevent two VMs from having the same network MAC address, which causes network IP conflicts.

--------------------------------------------------------------------------------
RESULT:
--------------------------------------------------------------------------------
The virtual machine was successfully migrated from the source computer to the destination computer
in a powered-off state (Cold Migration) using the OVA method, and all data was verified intact.
