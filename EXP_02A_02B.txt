--------------------------------------------------------------------------------
PART 1: EXPERIMENT 2a - CREATE A VM AND ALLOCATE RESOURCES
--------------------------------------------------------------------------------

AIM:
To create a Virtual Machine in Oracle VirtualBox, give it RAM, Hard Disk, and Network,
and test if Windows (Host) runs a Java program faster than Ubuntu (Virtual Machine).

--------------------------------------------------------------------------------
STEP-BY-STEP PROCEDURE (HOW TO CREATE VM):
--------------------------------------------------------------------------------
STEP 1: Create VM
1. Open Oracle VM VirtualBox.
2. Click the blue "New" button (star icon).
3. Type Name: KESHO_2A (or your name).
4. Type: Select "Linux".
5. Version: Select "Ubuntu (64-bit)".
6. Click "Next".

STEP 2: Give RAM (Memory)
1. Drag the slider to 2048 MB (2 GB) or 4096 MB (4 GB).
   (Note: Keep in the green bar area, do not cross 50% of your laptop RAM).
2. Click "Next".

STEP 3: Give Hard Disk (Storage)
1. Select "Create a virtual hard disk now" -> Click "Create".
2. Choose "VDI (VirtualBox Disk Image)" -> Click "Next".
3. Choose "Dynamically allocated" -> Click "Next".
4. Set size to 20 GB (or 25 GB) -> Click "Create".

STEP 4: Set Network Adapter
1. Click your new VM -> Click "Settings" (gear icon).
2. Click "Network" on left side.
3. In Adapter 1:
   - Check "Enable Network Adapter".
   - Attached to: Choose "Host-only Adapter".
4. Click "OK".

STEP 5: Add ISO File and Start
1. In Settings -> Click "Storage".
2. Under Storage Devices, click the round CD icon that says "Empty".
3. On the right side, click the blue CD icon -> Choose "Choose a disk file...".
4. Pick your Ubuntu ISO file -> Click "OK".
5. Click the green "Start" arrow to turn on your VM.

--------------------------------------------------------------------------------
PART 2: RUN JAVA PROGRAM TO COMPARE SPEED (WINDOWS VS LINUX VM)
--------------------------------------------------------------------------------

The Java Program (Benchmark.java):
--------------------------------------------------
public class Benchmark {
    public static void main(String[] args) {
        long startTime = System.currentTimeMillis();
        long sum = 0;
        for (long i = 1; i <= 500000000L; i++) {
            sum += (i % 10);
        }
        long endTime = System.currentTimeMillis();
        System.out.println("Sum is: " + sum);
        System.out.println("Execution Time: " + (endTime - startTime) + " ms");
    }
}
--------------------------------------------------

TEST 1: RUN IN UBUNTU VM (LINUX)
1. Open Terminal in Ubuntu (Ctrl + Alt + T).
2. Type command to create file:
   nano Benchmark.java
3. Paste the Java program inside.
4. Save and Exit:
   - Press Ctrl + O
   - Press Enter
   - Press Ctrl + X
5. Compile the program:
   javac Benchmark.java
6. Run the program:
   java Benchmark
   -> Look at the output time: e.g. 350 ms (or 0.35 s)

TEST 2: RUN IN WINDOWS HOST (LAPTOP)
1. Open Notepad in Windows.
2. Paste the same Java program inside.
3. Save it as "Benchmark.java" in any folder (like C:\lab\Benchmark.java).
4. Open Command Prompt (cmd) in Windows.
5. Go to your folder:
   cd C:\lab
6. Compile the program:
   javac Benchmark.java
7. Run the program:
   java Benchmark
   -> Look at the output time: e.g. 310 ms (or 0.31 s)

CONCLUSION / INFERENCE:
Windows Host took 310 ms, while Ubuntu VM took 350 ms.
Windows is FASTER because it runs directly on hardware (bare-metal), while the VM has
extra virtualization delay from the hypervisor.

--------------------------------------------------------------------------------
PART 3: EXPERIMENT 2b - PING TEST (VM-TO-VM AND VM-TO-HOST)
--------------------------------------------------------------------------------

AIM:
To check if two VMs can talk to each other, and if VM can talk to Windows host using the "ping" command.

STEP 1: Set Both VMs to Same Network
1. VM 1 (Ubuntu): Settings -> Network -> Adapter 1 -> "Host-only Adapter".
2. VM 2 (Kali / Ubuntu 2): Settings -> Network -> Adapter 1 -> "Host-only Adapter".
3. Start both VMs.

STEP 2: Turn OFF Firewall
1. On VM 1 (Ubuntu):
   sudo ufw disable
2. On VM 2 (Kali):
   sudo ufw disable
3. On Windows Host (Open cmd as admin):
   netsh advfirewall set allprofiles state off
   (Or allow ICMP in Windows Defender Firewall).

STEP 3: Check IP Addresses
1. In VM 1 (Ubuntu):
   ip a
   -> Find IP: e.g. 192.168.56.101
2. In VM 2 (Kali):
   ip a
   -> Find IP: e.g. 192.168.56.103
3. In Windows Host (cmd):
   ipconfig
   -> Find VirtualBox Host-Only Ethernet Adapter IP: e.g. 192.168.56.1

STEP 4: Run Ping Tests (Show to Examiner)
1. Ping from VM 1 to Host:
   ping -c 4 192.168.56.1
   -> 4 packets transmitted, 4 received, 0% packet loss!

2. Ping from Windows Host to VM 1:
   ping 192.168.56.101
   -> Reply received, 0% loss!

3. Ping from VM 1 (Ubuntu) to VM 2 (Kali):
   ping -c 4 192.168.56.103
   -> 4 packets transmitted, 4 received, 0% packet loss!

4. Ping from VM 2 (Kali) to VM 1 (Ubuntu):
   ping -c 4 192.168.56.101
   -> 4 packets transmitted, 4 received, 0% packet loss!

--------------------------------------------------------------------------------
SUPER SIMPLE VIVA QUESTIONS:
--------------------------------------------------------------------------------
Q1: What is Host-Only Adapter?
A: It is an internal private network between the host laptop and the virtual machines.

Q2: Why is Host faster than VM?
A: Host runs directly on real hardware. The VM runs on top of software (hypervisor), which adds extra delay.

Q3: What protocol does ping command use?
A: ICMP (Internet Control Message Protocol).

--------------------------------------------------------------------------------
RESULT:
--------------------------------------------------------------------------------
Virtual machine was created with custom RAM, Disk, and Network. Java benchmark showed
the host is faster than the VM. Ping tests between VM-to-Host and VM-to-VM succeeded with 0% packet loss.
