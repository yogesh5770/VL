================================================================================
EXPERIMENT 5a: INSTALL KVM & CREATE VIRTUAL INSTANCE
EXPERIMENT 5b: CREATE DISK IMAGE, RESIZE DISK & CONVERT FORMATS
================================================================================

AIM:
1. To install KVM (Kernel-based Virtual Machine) on Ubuntu and create a virtual machine instance.
2. To create a 10 GB virtual hard disk image, make it bigger (+5 GB), and convert it into
   different formats (RAW, VDI, VHD).

WHAT IS KVM?
KVM turns your Linux kernel into a Type-1 Hypervisor so you can run virtual machines at super fast speed.

WHAT IS QCOW2?
It is the standard disk format for KVM. It only takes up real hard disk space as you use it.

--------------------------------------------------------------------------------
STEP-BY-STEP PROCEDURE (5a - INSTALL KVM & CREATE INSTANCE):
--------------------------------------------------------------------------------

STEP 1: Check if Your CPU Supports Virtualization
Open Terminal in Ubuntu (Ctrl + Alt + T) and type:
   egrep -c '(vmx|svm)' /proc/cpuinfo
-> If the number is 1, 2, 4, or 8 (greater than 0), YES! Your CPU supports KVM!

STEP 2: Install KVM and Management Tools
Copy and paste this command and press Enter:
   sudo apt update
   sudo apt install qemu-kvm libvirt-daemon-system libvirt-clients virt-manager qemu-utils -y

STEP 3: Start the KVM Service & Give Permissions
Run these 3 commands:
   sudo systemctl enable --now libvirtd
   sudo usermod -aG libvirt $USER
   sudo usermod -aG kvm $USER

STEP 4: Test if KVM is Working
Type:
   virsh list --all
-> If it shows "Id  Name  State" with no errors, KVM is working perfectly!

STEP 5: Create a Test VM Instance (Using CirrOS Mini Image)
1. Download a tiny 15 MB test image:
   wget https://download.cirros-cloud.net/0.5.1/cirros-0.5.1-x86_64-disk.img

2. Open the graphical Virtual Machine Manager:
   virt-manager &

3. In the Virt-Manager window:
   - Click the top-left computer icon ("Create a new virtual machine").
   - Choose: "Import existing disk image" -> Click "Forward".
   - Click "Browse..." -> "Browse Local" -> Select the downloaded `cirros-0.5.1-x86_64-disk.img` file.
   - Memory: 512 MB | CPUs: 1 -> Click "Forward".
   - Name: `cirros-vm` -> Click "Finish".
4. The VM starts instantly! Log in with username: `cirros` and password: `cubswin:)`.
   (Success! You created a VM instance in KVM!).

--------------------------------------------------------------------------------
STEP-BY-STEP PROCEDURE (5b - DISK CREATION, RESIZING & CONVERSION):
--------------------------------------------------------------------------------

STEP 1: CREATE A 10 GB VIRTUAL DISK IMAGE
Run this command in Terminal:
   qemu-img create -f qcow2 mydisk.qcow2 10G

Check information about your disk:
   qemu-img info mydisk.qcow2
-> Look at the output:
   file format: qcow2
   virtual size: 10 GiB

STEP 2: RESIZE THE DISK (MAKE IT 5 GB BIGGER)
Suppose 10 GB is full, and you need to add 5 GB more space:
Run this command:
   qemu-img resize mydisk.qcow2 +5G

Check information again:
   qemu-img info mydisk.qcow2
-> Look at the output:
   virtual size: 15 GiB
(Success! Your virtual disk expanded from 10 GB to 15 GB!).

STEP 3: CONVERT DISK TO DIFFERENT FORMATS
You can convert this disk so it can work in VirtualBox or Hyper-V:

1. Convert QCOW2 to RAW format (.raw):
   qemu-img convert -f qcow2 -O raw mydisk.qcow2 mydisk.raw

2. Convert QCOW2 to VirtualBox format (.vdi):
   qemu-img convert -f qcow2 -O vdi mydisk.qcow2 mydisk.vdi

3. Convert QCOW2 to Microsoft Hyper-V format (.vhd):
   qemu-img convert -f qcow2 -O vpc mydisk.qcow2 mydisk.vhd

STEP 4: SHOW ALL CONVERTED FILES TO EXAMINER!
Type:
   ls -lh mydisk.*
-> You will see:
   mydisk.qcow2   (KVM format)
   mydisk.raw     (Raw format)
   mydisk.vdi     (VirtualBox format)
   mydisk.vhd     (Hyper-V format)

--------------------------------------------------------------------------------
SUPER SIMPLE VIVA QUESTIONS:
--------------------------------------------------------------------------------
Q1: What is KVM?
A: Kernel-based Virtual Machine. It is built into the Linux kernel to turn Linux into a Type-1 hypervisor.

Q2: What is QCOW2?
A: QEMU Copy-On-Write 2. It is a virtual disk format that grows in size only as files are written.

Q3: What tool is used to create and convert virtual disk images?
A: `qemu-img`.

Q4: What is the GUI tool for managing KVM?
A: `virt-manager` (Virtual Machine Manager).

RESULT:
--------------------------------------------------------------------------------
KVM was successfully installed on Linux, a virtual instance was created, and virtual disk images
were created, resized to 15 GB, and converted to RAW, VDI, and VHD formats without any errors.
